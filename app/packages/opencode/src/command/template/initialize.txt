## How to investigate

Use the task tool to delegate document reading to the explore subagent. The explore subagent will:
- Find and read text-based documents (PDF, DOCX, Markdown, plain text)
- Extract context from questionnaires, briefs, proposals, methodology documents
- Report findings with absolute file paths

Do NOT read files yourself — delegate all document exploration to the explore subagent.

Do NOT read or summarize numeric or statistics data files (CSV, Excel, SPSS, SAS, Stata, R data, MATLAB, dBase, columnar formats, JSON/JSONL/NDJSON). If data lives there, report where it is without reading it.

- What this project is about: goal, domain, and research questions.
- Structure: main directories, key documents, and where context lives.
- Methodology, protocol, references, or prior findings described in text documents.
- Absolute paths of the most relevant sources with a one-line note for each.
